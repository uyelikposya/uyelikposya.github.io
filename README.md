# uyelikposya.github.io

Catgrid Collection geliştirici sitesinin kökü.

- `app-ads.txt`: AdMob yetkili satıcı dosyası (Google, IAB app-ads.txt standardı). Uygulamanın
  App Store'daki pazarlama adresi `https://uyelikposya.github.io/...` olduğu için AdMob bu dosyayı
  `https://uyelikposya.github.io/app-ads.txt` adresinde arar.
- `index.html`: Uygulamanın sayfasına yönlendirir.

Bu dosyaların sitenin kökünde yayınlanması için depo adı tam olarak `uyelikposya.github.io` olmalıdır.
